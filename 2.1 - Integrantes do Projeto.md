# 👥 Integrantes e Divisão das Equipes — Projeto de Extensão DoaSync

## 📌 Organização

O projeto de extensão **DoaSync** será desenvolvido por equipes multidisciplinares, buscando distribuir os participantes de acordo com seus interesses, conhecimentos e necessidades de cada área do projeto.

A organização será composta por **5 equipes de trabalho**, que atuarão de forma integrada durante o desenvolvimento da solução.

A divisão das equipes considera os diferentes perfis apresentados pelos alunos, buscando combinar conhecimentos de **Produto, Front-end, Back-end, Banco de Dados, APIs, DevOps, Testes e Documentação**.

## 👑 Liderança das equipes

Cada equipe deverá definir internamente:

* **Líder**
* **Vice-líder**
* **Integrantes**

Os líderes serão responsáveis pela organização interna do grupo e pela comunicação com a equipe de gestão.

A liderança deverá atuar como facilitadora do trabalho, promovendo organização, comunicação e integração entre os integrantes.

---

## 📋 Equipe de Gestão

A equipe de gestão terá uma atuação transversal no projeto, acompanhando o trabalho das demais equipes e mantendo a comunicação com o cliente.

Suas principais responsabilidades serão:

* Organizar o andamento geral do projeto;
* Acompanhar os líderes;
* Coordenar as equipes;
* Organizar prioridades;
* Acompanhar os ciclos quinzenais;
* Identificar impedimentos;
* Facilitar a comunicação entre os grupos;
* Acompanhar as entregas;
* Consolidar informações do projeto;
* Manter o alinhamento com as demandas apresentadas pelo cliente.

---

## 🔗 Integração entre as equipes

As equipes não trabalharão de forma isolada.

Cada grupo possui uma responsabilidade principal, mas poderá atuar em conjunto com outras equipes sempre que houver dependências.

A integração entre os grupos será fundamental para garantir que as diferentes partes do sistema funcionem como uma única solução.

## 🎯 Objetivo da divisão

A divisão busca formar equipes multidisciplinares, evitando a concentração de conhecimentos em apenas um grupo.

Cada equipe deverá possuir integrantes com diferentes níveis de experiência e conhecimentos complementares.

A proposta é estimular:

* Trabalho em equipe;
* Compartilhamento de conhecimento;
* Aprendizagem entre os integrantes;
* Comunicação entre áreas;
* Desenvolvimento de liderança;
* Autonomia;
* Responsabilidade coletiva.

A composição das equipes poderá ser ajustada ao longo do projeto conforme as necessidades identificadas durante os ciclos de desenvolvimento.

---

## 📌 Observação

A atuação indicada para cada integrante representa sua **principal área de contribuição**.

Os alunos poderão atuar em outras atividades ao longo do projeto, especialmente quando houver necessidade de integração entre as equipes ou oportunidade de desenvolvimento de novas competências.

O objetivo não é limitar o aluno a uma única tecnologia, mas proporcionar uma experiência ampla de desenvolvimento de software.
